Nama Dataset : Mushroom Classification 

Sumber : Kaggle

Tautan:https://www.kaggle.com/datasets/uciml/mushroom-classification/data

Deskripsi singkat: Dataset Mushroom Classification (berasal dari UCI Machine Learning Repository via Kaggle) merupakan salah satu dataset klasik yang populer dalam bidang pembelajaran mesin (machine learning) untuk tugas klasifikasi biner. Dataset ini dirancang untuk mengidentifikasi apakah suatu spesies jamur dikategorikan sebagai layak makan (edible) atau beracun (poisonous).
